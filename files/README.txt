WebCraft – ملفات التدريب

لكل تمرين مجلد فيه 3 ملفات: index.html و style.css و script.js، ومجلد images فيه صورة مؤقتة.

01-tamreen1-start           بداية التمرين الأول (تعليمات داخل الكود)
02-tamreen1-solution        حل التمرين الأول: الصفحة التعريفية (HTML)
03-tamreen2-solution        حل التمرين الثاني: التنسيق (CSS)
04-tamreen3-solution        حل التمرين الثالث: التصميم المتجاوب
05-tamreen4-solution        حل التمرين الرابع: زر الوضع الليلي (JavaScript)
06-final-project-template   قالب المشروع النهائي
editor                      محرر الهاتف كملف واحد (index.html) يمكن رفعه على أي استضافة

على الحاسوب: افتح المجلد في VS Code ثم شغّل index.html بإضافة Live Server.
على الهاتف: استخدم رابط محرر WebCraft؛ فيه نفس التمارين والحلول جاهزة في القائمة العلوية.
